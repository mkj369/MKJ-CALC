Help

Getting started

  • প্রথমে মডেল বাছুন: 991 ES Plus, 991 EX Plus, 991 CW.
  • তারপর mode বাছুন — Calculate, Complex, Statistics, Matrix, Vector, Equation, Base-N, Ratio, Table, Solve, Verify, Constants.

Keys

  • SHIFT → কী-এর উপরের হলুদ ফাংশন; ALPHA → লাল ভেরিয়েবল।
  • S⇔D → দশমিক ↔ ভগ্নাংশ ↔ π-form।
  • CALC → ভেরিয়েবলের মান বসিয়ে হিসাব। SOLVE → f(x)=0 এর root।
  • ∫dx, d/dx, Σ, Π কাজ করে; যেমন ∫(x^2,0,3), ∑(x^2,1,10)।
  • ইমাজিনারি: i লিখুন — (3+4i)*(1-2i).
  • MODE/MENU/HOME → mode তালিকায় ফিরে যান।

Physical keyboard

  • সংখ্যা ও + − * / ^ ( ) সরাসরি; Enter = equals, Backspace = DEL, Esc = AC
  • Shift+Enter = S⇔D, ↑ ↓ = history, ← → = caret
