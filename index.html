Quick help

Models

  • 991 ES Plus — classic layout, natural display, S⇔D conversion.
  • 991 EX Plus — 4-line class display, MATRIX / VECTOR / CONST menu keys.
  • 991 CW — newer flat-pad design with a round HOME button.

Display

  • Type an expression and press =.
  • S⇔D swaps between fraction and decimal.
  • Ans shows the last result on screen; STO then a variable stores it.
  • x10ˣ enters an exponent of ten, ×10ˣ for engineering-style entry.

Keyboard

  • 0–9 . + − * / — literal keys
  • Enter = equals, Backspace = DEL, Esc = AC
  • Shift+Enter = S⇔D
